# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| `0.3.x` | Yes |
| `0.2.x` | Yes |
| `< 0.2.0` | No |

## Reporting a Vulnerability

If you discover a security issue in CopyWheel, please report it privately using GitHub Security Advisories (**Security → Advisories → Report a vulnerability** in the repository). Please do not open a public issue for undisclosed security bugs.

Include a description of the issue, steps to reproduce, and the affected version. You can expect an initial response acknowledging the report and next steps for remediation.

## Automated Security Checks

Every push and pull request (and a weekly scheduled run) runs the following checks in GitHub Actions:

- **Build & test CI** (`.github/workflows/ci.yml`): formatting (`cargo fmt --check`), linting (`cargo clippy --all-targets --locked -- -D warnings`), and tests (`cargo test --locked`) on `macos-latest` and `windows-latest`.
- **Dependency & license auditing** (`cargo-deny` with `deny.toml` in `.github/workflows/security.yml`): denies known security advisories, enforces an AGPL-3.0-compatible license allow list, warns on duplicate dependency versions, and restricts crates to `crates.io`.
- **Secret scanning** (`gitleaks` in `.github/workflows/security.yml`): scans full git history for leaked credentials.
- **Workflow static analysis** (`zizmor` in `.github/workflows/security.yml`): audits `.github/workflows` for insecure workflow patterns and fails on medium or higher findings.
- **Dependency updates & code scanning**: Dependabot updates Cargo and GitHub Actions dependencies weekly (grouped for minor/patch updates), and repository security settings enable Dependabot security updates and CodeQL code scanning for Rust and GitHub Actions.

## Data Storage and Permissions

CopyWheel stores all user data locally:

- **macOS:** `~/Library/Application Support/CopyWheel/`
- **Windows:** `%APPDATA%\CopyWheel\`

Files stored in the data directory:

- `data.json` — Clipboard text history, favorites, groups, settings, and last-used snippet variable values, stored as plain-text JSON.
- `images/` — Captured clipboard images.

### File permissions

- On macOS, the data directory is created with permissions `0700` (owner access only), and `data.json`, files in `images/`, temporary files, and exported backups are written with permissions `0600` (owner read/write only).
- On Windows, user data is stored in the current user's `%APPDATA%\CopyWheel\` profile directory.
- If `data.json` fails to parse on startup, CopyWheel renames it to `data.json.corrupt-<timestamp>` rather than overwriting it.

### Clipboard filtering and exports

- By default, CopyWheel skips clipboard entries marked as concealed, transient, or auto-generated (on macOS: `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`; on Windows: `ExcludeClipboardContentFromMonitorProcessing`, `Clipboard Viewer Ignore`, and `CanIncludeInClipboardHistory` set to `0`) so copies from password managers are not stored.
- Exported backups are written as plain text; treat them as sensitive files.

## Network Access

CopyWheel does not open network connections, send telemetry, or perform automatic update checks. All functionality runs strictly offline.

## Dependency Advisories

- `RUSTSEC-2026-0192` marks `ttf-parser` as unmaintained. egui's font rasterizer uses it to read bundled and system fonts. CopyWheel accepts no untrusted font input. Tracked for the next egui upgrade.
